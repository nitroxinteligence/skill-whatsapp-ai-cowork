# Agente de WhatsApp Comercial & Follow-up (`skill-whatsapp-ai-cowork`)

> Skill oficial distribuída pela **AI Cowork Academy** para empresários e gestores estruturarem **WhatsApp & Atendimento** com Agentes de IA.

## O que este agente faz

Cria sequências humanas de WhatsApp, fluxos de atendimento, qualificação e retomada de leads que pararam de responder.

## Como instalar em 1 comando

Copie e cole este prompt direto na sua IA (Claude Code, Codex, ChatGPT ou Antigravity):

```text
Acesse o repositório https://github.com/nitroxinteligence/skill-whatsapp-ai-cowork, leia o arquivo SKILL.md completo (e a pasta references/) e instale esta skill no meu workspace para eu usar agora.
```

## Como utilizar na prática

Informe em qual etapa o lead parou (orçamento, diagnóstico ou pós-reunião) e o produto ofertado. O agente escreve mensagens curtas e naturais para retomar a conversa.
